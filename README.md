# 🌐 VLESS Configuration & Routing Research Lab

This repository is a dedicated research environment for monitoring, testing, and benchmarking the performance and routing stability of the VLESS protocol (tcp/xhttp) across various international network nodes.

## 🚀 Project Overview
The objective of this project is to analyze network latency, packet loss, and uptime statistics for over 25 geographic locations. All configuration profiles are updated regularly to maintain data accuracy for telecommunication analysis.

## 📂 Repository Structure
- `by-country/` — Individual text documents containing specific node parameters grouped by country for localized latency mapping. (COMING SOON)
- `configs.txt` — Unified routing matrix configuration, optimized for multi-node subscription and diagnostic scripts.

## 📱 Technical Implementation
These configuration streams are compatible with standard network analysis clients that support V2Ray/Xray cores, including but not limited to:
- Hiddify / HiddifyN
- NekoBox
- v2rayN
- FoXray / Streisand
